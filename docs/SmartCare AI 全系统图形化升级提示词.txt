颜色使用规则：

- 红色只表示危急、失败、强制阻断。
- 橙色表示高风险或需要尽快处理。
- 黄色表示提醒或需要关注。
- 绿色表示正常、完成或恢复。
- 蓝色表示信息、选择和一般趋势。
- 紫色表示AI生成、AI建议或模型状态。
- 灰色表示缺失、未知、不可用和已停用。

禁止：

- 用绿色表示AI结论。
- 用红色装饰普通按钮。
- 在同一个页面使用多套风险颜色。
- 仅依靠颜色区分状态。

所有状态必须同时提供：

- 颜色
- 图标
- 文字
- 必要时增加形状或边框差异

优先使用系统字体。

字号：

- 系统名称：18px / 600
- 页面标题：20px / 600
- 患者姓名：18px / 600
- 区块标题：16px / 600
- 卡片标题：14px / 600
- 正文：14px / 400
- 辅助说明：12px / 400
- 表格内容：13px / 400
- 指标大数字：24px至32px / 600
- ICU大屏数字：32px至44px / 600
- 图表坐标轴：11px至12px
- 图例：12px
- Tooltip：12px至13px

行高：

- 正文：1.5至1.7
- 表格：1.4
- 标题：1.3
- 大数字：1.15

文字要求：

- 一个卡片标题不超过16个汉字。
- 图表解释限制在2至4行。
- 告警标题必须先写异常，再写原因。
- 禁止连续出现超过300字的大段文字。
- 长说明使用“结论摘要＋展开详情”。
- 专业缩写第一次出现时提供中文解释。
- 数字与单位不得分离。
- 时间必须显示日期、时间和统一时区。

圆角：

- 普通卡片：8px
- 弹窗：10px
- 标签：4px或胶囊形
- 按钮：6px
- 输入框：6px

阴影：

默认卡片仅使用浅阴影：

0 1px 3px rgba(16, 24, 40, 0.08)

悬浮卡片：

- 大面积悬浮阴影
- 玻璃拟态

普通业务页统一结构：

第一层：页面上下文

- 页面标题
- 患者或科室
- 当前时间范围
- 最后更新时间
- 数据状态
- 主要操作

每页3至6个关键指标，不超过8个。

指标卡必须包含：

- 指标名称
- 当前值
- 单位
- 状态
- 与上个周期对比
- 小型趋势线
- 数据时间
- 点击后的明细入口

第三层：主要可视化

每页只设置1至2张主要图。

第四层：过程或证据

使用：

- 时间线
- 流程图
- 证据图
- 状态机
- 责任人任务流
- 数据来源说明

第五层：明细数据

详细表格放在页面下部或抽屉中。

表格不是页面第一视觉焦点，除非该页面本身就是记录查询或配置管理。

十二、AI问诊页面
━━━━━━━━━━━━━━━━━━━━

“AI对话与结论”

1. 临床结论
2. 风险等级
3. 支持证据

5. 建议动作
6. 需要补充的数据
7. 免责声明与使用边界

“AI证据与来源”

- 患者原始数据
- 临床规则
- 评分结果
- 本地知识库
- 引用时间
- 模型版本
- 置信或确定性说明

- 器官风险
- 评分趋势
- 风险变化
- 数据完整度

AI证据图：

患者数据

二十六、图表选择原则
━━━━━━━━━━━━━━━━━━━━

趋势变化：

使用折线图、面积图、阶梯图、Sparkline。

构成：

优先使用堆叠条形图。
只有类别小于等于5个时才考虑环图。
尽量不使用饼图。

流程：

使用SVG、ECharts Graph、Sankey或CSS节点流程。

时间事件：

使用时间线、事件河流图、泳道图。

多个指标对比：

使用分组条形图、热力图、点图。
谨慎使用雷达图。

临床评分：

使用总分趋势＋分项堆叠图。
不使用仪表盘代替评分趋势。

关系和证据：

使用有向关系图。
节点数量过多时分层折叠。

统计分析：

使用符合统计目的的专业图形。
禁止只为了好看选择图表。

地图：

没有真实地理需求时不使用地图。

3D：

只有人体器官定位或确有空间关系时使用。
普通业务指标禁止使用3D柱状图和3D饼图。
