# 全系统页面视觉审计表

## 审计说明

本表覆盖 icu-alert-system 前端全部路由页面。每页评估当前视觉状态、文字/表格过多区域、可图形化数据、推荐图形、接口需求和改造优先级。

优先级：P0 = 核心临床页面（直接影响患者安全决策），P1 = 临床协同页面，P2 = 管理运营页面，P3 = 科研/配置页面。

---

## 1. 医生首页 (DoctorHome)

| 维度 | 现状 |
|------|------|
| **路由** | `/doctor-home` |
| **用户角色** | 医生 |
| **当前布局** | 顶部指标卡 + 患者列表表格 + 告警列表 |
| **当前主要内容** | 在科患者数、告警统计、患者列表（表格）、待办任务 |

| **表格过多区域** | 患者列表、告警列表均为纯表格 |
