# 患者详情页线框图

## 页面定位

患者详情是整个系统最重要的临床页面。用户应该能：
1. 第一眼：看懂患者当前状态
2. 第二眼：找到异常和风险变化
3. 第三眼看清系统为什么做出判断
4. 第四眼知道下一步应该处理什么

## 页面区块说明

### 第一层：患者上下文条
- **内容**: 床号、姓名、性别、年龄、住院号、入ICU时间、主要诊断、过敏、隔离、当前风险、数据更新时间
- **操作**: 时间范围切换、刷新、更多菜单
- **固定**: 顶部固定，滚动时保持可见

### 第二层：关键指标（左列顶部）
- **器官风险人体图**: SVG，按器官系统显示风险等级，点击查看相关指标和告警
- **当前评分**: SOFA、NEWS2、qSOFA 大数字显示
- **主要诊断**: 简短文字
- **设备导管**: 图标+名称列表
- **数据完整度**: 环形进度条

### 第三层：主要可视化（中列）
- **多指标生命体征趋势**: ECharts多Y轴折线图
  - 支持6h/12h/24h/72h/7d切换
  - 可打开/关闭指标
  - 显示正常范围带
  - 显示用药/手术/插管等事件标记
  - 显示数据缺口
  - 显示单位
- **评分趋势图**: SOFA/NEWS2/qSOFA趋势折线图
- **检验趋势图**: 关键检验指标趋势
- **24h临床事件时间线**: 水平泳道图

### 第四层：过程与证据（右列）
- **当前告警**: 告警列表，按紧急度排序
- **AI临床摘要**: 结构化AI分析（紫色左边框标识）
- **建议动作**: 可执行的动作列表
- **最近文书**: 文书时间线
- **MDT状态**: 当前MDT状态

## 图表类型

| 区块 | 图表类型 | 库 |
|------|----------|-----|
| 器官风险人体图 | 本地SVG + 状态色 | SVG |
| 生命体征趋势 | 多Y轴折线图 + 标记线 | ECharts |
| 评分趋势 | 折线图 | ECharts |
| 检验趋势 | 折线图 | ECharts |
| 事件时间线 | 泳道图/时间线 | ECharts custom / SVG |
| 数据完整度 | 环形进度条 | ECharts / CSS |

## 数据字段

| 区块 | 字段 | 来源 |
|------|------|------|
| 患者信息 | name, gender, age, bedNo, admissionTime, diagnosis, allergies, isolation | /api/patients/{id} |
| 生命体征 | hr, sbp, dbp, map, spo2, rr, temp, timestamp[] | /api/patients/{id}/vital-trends |
| 评分 | sofa, news2, qsofa, components[], timestamp[] | /api/patients/{id}/score-trends |
| 器官风险 | organ[], riskLevel, evidence[] | /api/patients/{id}/organ-risk |
| 事件时间线 | events[]: type, time, description, source | /api/patients/{id}/clinical-timeline |
| 告警 | alerts[]: level, title, time, status | /api/patients/{id}/alerts |
| 治疗响应 | interventions[], before, after, effect | /api/patients/{id}/treatment-response |

## 用户操作

| 操作 | 说明 |
|------|------|
| 切换时间范围 | 趋势图X轴范围切换 |
| 点击器官 | 打开侧边抽屉，显示该器官相关指标、告警、证据 |
| 点击告警 | 跳转告警详情或展开告警处理面板 |
| 点击建议动作 | 执行动作或跳转对应页面 |
| 展开AI摘要 | 查看完整AI分析和证据链 |
| 查看原始数据 | 打开数据表格抽屉 |

---

## 下钻路径

```
患者详情
├→ 器官风险详情（侧边抽屉）
│   ├→ 相关指标趋势
│   ├→ 相关告警
│   └→ 证据和规则
├→ 告警详情
│   ├→ 触发规则
│   ├→ 原始数据
│   └→ 处置记录
├→ 评分详情
│   ├→ 分项得分
│   └→ 计算依据
└→ 原始数据表格
```

## 空状态

| 区块 | 空状态处理 |
|------|-----------|
| 器官风险图 | 无数据器官显示灰色"未知"，不显示正常 |
| 生命体征趋势 | 显示"暂无生命体征数据，请检查监护仪连接" |
| 评分趋势 | 显示"暂无评分数据" |
| 事件时间线 | 显示"过去24小时无记录事件" |
| 告警 | 显示"当前无活跃告警" |
| AI摘要 | 显示"AI分析需要至少2小时数据积累" |

---

## 错误状态

| 区块 | 错误处理 |
|------|---------|
| 接口超时 | 显示"数据加载超时" + 重试按钮 |
| 接口失败 | 显示"数据获取失败" + 错误码 + 重试 |
| 数据过期 | 显示"数据已过期(超过30分钟)" + 刷新按钮 |
| 患者已出科 | 显示"患者已出科" + 跳转患者列表 |
