## 页面定位

智能查房帮助医生在查房时快速了解患者过去24小时发生了什么、当前最重要的问题是什么、各器官系统状态如何、治疗效果如何。

## 页面区块说明

### 页面标题区
- 查房患者信息
- 查房状态（进行中/已完成）
- 参加人员
- 开始时间
- 数据更新状态
- 一键生成查房摘要

### 第一部分：过去24小时发生了什么
- **图表类型**: ECharts自定义泳道图（临床事件河流）
- **泳道**: 生命体征、检验、用药、呼吸治疗、液体、评分、告警、操作
- **交互**: 点击事件查看详情
- **时间范围**: 可切换12h/24h/48h

### 第二部分：当前最重要的问题
- 问题卡片列表
- 每张卡片显示：问题名称、严重度、证据数量、最近变化、是否已处理、是否需复评
- 颜色对应风险等级

### 第三部分：器官系统查房
- **器官热力图**: 9个器官系统的风险热力矩阵
- **分项卡**: 每个器官系统一个卡片，显示评分、关键指标、趋势
- 点击器官查看详细趋势

### 第四部分：治疗响应
- **图表类型**: 治疗前后对比表格
- 行：干预项目
- 列：干预前、采取措施、当前值
- 显示变化方向箭头

### 第五部分：查房闭环
- **图表类型**: 流程图（SVG/CSS节点）
- 节点：发现问题→形成判断→制定计划→分配责任人→执行→复评→关闭
- 每个节点显示完成/进行中/待处理状态
- 统计完成率
