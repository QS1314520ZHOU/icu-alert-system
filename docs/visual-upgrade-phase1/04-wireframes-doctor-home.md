# 医生首页线框图

## 页面定位

医生首页是医生进入系统后的第一个页面，需要快速回答：
1. 我管的患者现在整体什么情况？
2. 哪些患者最需要关注？
3. 我现在应该做什么？

## 页面区块说明

### 第一层：页面上下文
- 页面标题：医生工作台
- 科室名称
- 当前时间
- 刷新按钮
- 大屏模式切换

### 第二层：关键指标（6个）
| 指标 | 说明 | 数据 |
|------|------|------|
| ICU在科患者数 | 当前管床患者总数 | 数字+同比 |
| 危急患者数 | 风险等级为危急的患者 | 数字+变化箭头 |
| 新增高风险数 | 本班新增高风险 | 数字 |
| 未签收告警数 | 待签收的告警 | 数字+同比 |
| 即将超时任务数 | 2小时内到期的任务 | 数字+同比 |
| 夜间重要事件数 | 过去12小时重要事件 | 数字 |

### 第三层：患者风险矩阵（左侧16格）
- **图表类型**: ECharts散点图
- **横轴**: 当前风险分数（0-100）
- **纵轴**: 风险变化速度（过去4小时变化率）
- **点大小**: 未处理问题数量
- **点颜色**: 风险等级颜色
- **交互**: 点击患者点跳转患者详情
- **Tooltip**: 床号、姓名、诊断、当前风险、变化趋势

### 第三层：今日重点处置（右侧8格）
- 危急需处理
- 即将超时
- 等待复评
- 等待会诊
- 等待检查结果
- 每项显示数量+列表+操作按钮

### 第四层：重点患者趋势（左侧）
- 表格形式，每行显示：床号、姓名、诊断、风险等级、迷你趋势图
- 迷你趋势图为Sparkline，显示最近24小时关键指标

### 第四层：24小时告警漏斗（右侧）
- **图表类型**: ECharts漏斗图
- **层级**: 告警触发 → 有效告警 → 已签收 → 已处置 → 已关闭
- **每层显示数量和比例**
- **交互**: 点击层级下钻到对应告警列表
